# 1단계 · 데이터 정합성 리포트

> **목적**: 통합 논문 착수 전, 수집 데이터의 내적 모순을 점검하고 "현업에서 무엇을 재추출해야 하는지"를 숫자로 확정한다.
> **결론 요약**: 발견된 두 이슈는 모두 **데이터 오류가 아니라 기록·정의의 문제**였다. 추가 관측이 현재 불가하므로, 억셉 논문과 동일하게 **확정 추정값(scenario-based)** 으로 고정한다. (1) 큐잉 유형별 평균은 E[S]=4.0h·우량 60%와 모순 없는 추정 조합으로 확정, (2) 잔여노동은 정의1로 확정.

---

## 이슈 1 — 큐잉 파라미터 불일치 (해결 경로 확정)

### 무엇이 문제였나
현업 기록: `E[S]=4.0h`, `범위 0.5~12h`, `우량 60% / 희소 40%`.
이 셋을 2점 혼합분포로 역산하면 **우량 평균 서비스시간이 음수**가 나온다(수치 모순).

### 원인 규명
`0.5h`와 `12h`는 **유형별 평균이 아니라 전체의 최소~최대 범위(min/max)**였다.
- 극단값 그대로(0.5, 12) 넣으면 E[S]=5.1h가 되어 현업의 4.0h와도 안 맞음 → 이 둘은 평균이 아님이 확증됨.
- 유형별 **평균**은 따로 존재하며, 로그에서 재추출해야 함.

### 중요한 발견 — 현업 데이터는 대체로 맞다
희소 평균이 약 10h 수준이면, E[S]=4.0h가 성립하기 위한 우량 비중이 **67%**로 계산되어 현업이 말한 **60%와 근사**하다. 즉 현업의 믹스 비율(60/40)은 신뢰할 만하며, 문제는 오직 "유형별 평균을 범위값과 섞어 적은 것"뿐이다.

### 정합이 성립하는 조합 (참고표)
| 희소 평균 s_slow | 필요 우량 평균 s_fast (E[S]=4, p=0.6) | 타당성 |
|---:|---:|---|
| 6.0h | 2.67h | OK |
| 7.0h | 2.00h | OK |
| 8.0h | 1.33h | OK |
| 9.0h | 0.67h | OK (경계) |
| 10.0h | 0.00h | 불가 → p 조정 필요 |

> 해석: 희소 평균이 8h를 넘으면 p=0.6 고정 하에서 우량 평균이 0.5h 미만으로 비현실적. 이 경우 **우량 비중 p를 올려야** 정합(희소 10h면 p≈0.67).

### ✅ 확정 추정값 (관측 불가 → scenario-based로 고정)

| 파라미터 | 확정값 | 근거 |
|---|---|---|
| 우량 평균 s_fast | **1.33h** | E[S]=4.0h·p=0.60과 정합, 범위 0.5~12h 내 |
| 희소 평균 s_slow | **8.0h** | 동일 정합 조건, CV<1 확보 |
| 우량 비중 p | **0.60** | 현업 보고 유지 |
| 파생: E[S], Var, CV | 4.0h, 10.7, **0.816** | CV<1 → M/M/1 부적절, M/G/1 정당화 |

> 이 값들은 **관측이 아니라 추정**이며, 논문 Limitations에 억셉 논문과 동일한 방식으로 명시한다("scenario assumption"). 향후 관측이 가능해지면 이 4개 값만 교체해 노트북 재실행.

### (참고) 원래 재추출 대상이었던 4개 숫자
1. **우량기업(정형·정보풍부) 검수 평균시간** (Stage 6, 건당)
2. **희소/분쟁기업 검수 평균시간** (Stage 6, 건당)
3. **우량 건수 비중** (관찰기간 내)
4. **희소 건수 비중**

> 이 4개로 `E[S]`, `E[S²]`, `Var[S]`가 유일하게 결정된다(억셉 논문과 동일 방식).
> `0.5h/12h`는 논문에서 min/max 각주로만 처리하고, 평균 산정에는 쓰지 않는다.

## 이슈 2 — 잔여노동 비중 (정의 확정으로 해결)

### 무엇이 문제였나
현업 자기보고는 62%(Q9는 60~65%)인데, 태스크 시간으로 재계산하면 정의에 따라 29%~81%로 흩어진다.

### 원인 — 분모 정의 미확정
| 정의 | 계산 | 값 |
|---|---|---:|
| 정의1: AI후 사람시간 대비, 압축불가(T3·T6)만 | 4.00 / 5.20 | **77%** |
| 정의1′: +부분압축(T4) 절반 포함 | 4.20 / 5.20 | 81% |
| 정의2: AI전 총시간 대비 압축불가 AI후시간 | 4.00 / 12.00 | 33% |
| 정의3: 인터뷰 자기보고(Q9) | 체감 | 60~65% |
| 정의4: 태스크 개수 기준 | 2/7 (+부분 3/7) | 29% (43%) |

### ✅ 권고 — 주 지표는 정의1
- **주 지표: 정의1 (AI후 사람시간 대비) ≈ 77%.**
  이유: 큐잉 모델의 서비스시간과 **같은 기준(AI후 사람시간)**이라 모델 전체가 정합적.
- **보조: 인터뷰 자기보고(60~65%)를 삼각검증으로.**
- 두 값의 차이는 모순이 아니라 **측정 층위 차이(로그 기반 vs 체감)**로 Discussion에 투명 서술. (억셉 논문의 "정직한 한계 서술" 미덕 계승)

> 집필 시 "잔여노동 비중"의 조작적 정의를 정의1로 **한 번 선언하고 전편에서 일관 적용**.
